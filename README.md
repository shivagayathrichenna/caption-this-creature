# Caption This Creature 🎮

An interactive multiplayer-style party game focused on dynamic captioning and creature-based prompts, built using advanced AI prompt engineering on Arena.ai.

## About The Project
"Caption This Creature" is a creative web-based party game designed to test quick thinking, humor, and storytelling. Players receive unique creature visuals and prompts, and the objective is to generate the most engaging and witty captions.

## Tech Stack & Tools
* **Platform/Prototyping:** Arena.ai
* **Frontend Logic:** HTML, JavaScript, CSS
* **Core Concepts:** Generative AI, Prompt Engineering, Game State Management

## Features
* Dynamic creature and prompt generation workflows.
* Interactive scoring and gameplay loops.
* Clean and responsive user interface layout.
